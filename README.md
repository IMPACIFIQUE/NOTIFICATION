# NOTIFICATION

A custom alert box built with HTML, CSS and JavaScript. It shows how to design your own alert box instead of using the plain browser `alert()`.

## Features

- Popup alert box with an overlay behind it
- Styled with CSS
- Close button to dismiss the alert



## Run It

1. Download or clone the repository.
2. Open `alertbox.html` in your browser.
